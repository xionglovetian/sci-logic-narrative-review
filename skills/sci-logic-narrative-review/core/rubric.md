# 评分与路径判定

## 使用顺序（不可颠倒）

```
先查硬阈值（F1–F6 致命项）
      │
      ├─ 命中任一 ──────────────► P-C（无论总分多高）
      │
      └─ 全未命中 ─► 查 P-A 门槛
                          │
                          ├─ 全满足 ─► P-A
                          └─ 未全满足 ─► P-B
```

**总分只用于排序与展示，不用于判定。** 这是本 rubric 最重要的一条设计：一篇 78 分但缺等容量对照的稿子，路径是 P-C，不是 P-A；一篇 55 分但对照扎实、缺口成立的稿子，路径是 P-B，且很可能中修接受。

分数用来回答"离下一档还差多少"，路径用来回答"现在能不能投"。两者的职责不能混。

## 一、七维评分表（满分 100）

| 维度 | 分值 | 满分条件 | 扣分规则 |
|---|---|---|---|
| **A 缺口真实性** | 20 | 指向被默认的隐含假设；量化说明失效后果；有负向证据；与实验一一对应 | 空话 −12；无证据断言 −8；太泛 −4；与实验不对应 −6 |
| **B 方案对症性** | 15 | 每模块对应一条缺陷；有互补逻辑；工程属性有代价说明 | 模块无对应 −6/个；动机写成"提升性能" −4；完全脱节 −8 |
| **C 因果闭环** | 30 | 三层齐备；等容量对照与统计检验均有；负向结果保留 | 无等容量对照 −18；无统计检验 −8；无负向结果 −6；控制变量不唯一 −8；无泛化 −5 |
| **D 贡献可分性** | 15 | 三处摆放一致；三条独立且有专属支撑；分类清晰；表述量化 | 同质化 −8；缺一处摆放 −4；无支撑 −5；表述模糊 −3 |
| **E 图表分层** | 10 | 机制图足；表已分组；显著性标注齐；有趋势图 | 无机制图 −4；表混装 −3；缺显著性标注 −3；无趋势图 −2 |
| **F 边界自限** | 10 | 有机理；有文献本质区分；有失效条件；回应对照质疑 | 讨论复述结果 −5；无失效条件 −4；全称声明 −6；无文献区分 −3 |
| **G 数字可溯源** | **必扣项** | 全部可溯源 | 不可溯源 −5/条；与台账矛盾 −15/条；口径不一致 −8/条（总分可为负，负分按 0 计但必报） |

**G 是必扣项**：其它六项是加分制，G 是减分制，直接从总分里扣。一条"数字与台账矛盾"就足以把 90 分的稿子压到 75 分——但请注意，**75 分并不改变路径判定**，改变路径的是 F2。

### 计分口径（避免各写各的）

```
A+B+C+D+E+F（满分 100）  →  减掉 G 的扣分  →  最终分（下限 0）
```

- 各维度扣分只能减到 0，不为负；A–F 合计上限 100、下限 0。
- G 的扣分不设上限（多条矛盾可累计），但最终分不低于 0。
- 报告里必须写出中间过程（`A–F 合计 X 分，G 扣 Y 分，最终 X−Y`），否则无法复核。

### 评分纪律

- 每个维度只给一个整数分，不写区间。
- 打分必须能指回清单条目（如"C=14/30，因为 3.2.1 缺失"）。
- 不评"印象分"。第 A 维没有"感觉不错"这种给分理由。

## 二、硬阈值：P-C 判定条件（命中任一即 P-C）

| 条件 | 对应致命项 | 判据原文 |
|---|---|---|
| C1 | F1 | 性能提升伴随参数量/计算量增加，且**无**等容量控制对照 |
| C2 | F2 | 关键数字不可溯源，或与台账矛盾，或同一指标两值并存 |
| C3 | F3 | 存在因果动词/因果声明，但**无**对应控制实验 |
| C4 | F4 | 存在"通用/普适/任意场景"类全称声明，且无跨域证据 |
| C5 | F5 | 负向/失败结果被系统性隐去（不是"没做"，而是"做了不报"） |
| C6 | F6 | 存在疑似数据或图像完整性问题 |
| C7 | 追加 | 输入完整度为 G2 严重缺口，且无法从任何来源确认核心数字 |

> **C1 与 C3 的区别**：C1 是"对照没做"，C3 是"没做还硬说成因果"。C3 更重，因为它同时违反证据与措辞两条线。两者常同时命中，报告里分别列卡片。

**P-C 的处置**：不是"改改就能投"，是**先补实验或先撤声称**。撤声称后可能降为 P-B（见下方"叙事降级"）。

## 三、P-A 门槛（全部满足才是方法创新型）

| P-A1 | 存在与方案等容量/等计算量的对照组，且该对照组**明显弱于**本方案 |
| P-A2 | 主对比有统计检验支撑，提升幅度超出随机波动（p<0.05 或均值差距 > 2×标准差） |
| P-A3 | 单模块消融齐备，包含"等参数占位"消融，证明是设计而非容量 |
| P-A4 | 缺口成立且有负向证据支撑 |
| P-A5 | 三条贡献独立可分，各有专属实验，且因果表述不越界 |
| P-A6 | 讨论有机理解释 + 失效条件，未做全称声明 |

**"明显弱于"的操作化定义**（避免主观）：控制组相对本方案的性能差距 ≥ 2 倍标准差，或相对提升 ≥ 3% 且 p<0.05。达不到即视为"差距很小"，走 P-B。

**P-A 还要能通过一句反问**：「把你们的模块换成同样参数量的随机堆叠，性能会掉多少？」作者能以实验数据直接回答，才算过 P-A1。

## 四、P-B 判定与"叙事降级"（本 skill 最实用的动作）

**P-B 触发**：未命中任何 P-C 硬阈值，但未满足 P-A 全部条件——典型情况是 C1 存在（对照缺失或差距微弱）而不存在 C3（作者没有宣称因果）。

此时**必须做叙事降级**，把稿件从"方法创新型"改判为"评估认知型"，具体动作：

| 要降的东西 | 降法（原→改） |
|---|---|
| 标题 | 去掉"新的/novel/efficient framework"类词，改为"揭示…评估陷阱""重新审视…" |
| 摘要结论句 | 从"所提方法显著优于基线"→"在 X 协议下，本文量化揭示 Y 假设导致 Z 偏差，并给出缓解策略" |
| 贡献第②条 | 从"提出 XX 方案"→"给出针对 Y 偏差的可插拔缓解策略，其收益在等预算条件下可复现" |
| 章节标题 | "Method"保留但弱化为"Mitigation Strategy"；"Ablation"改"Controlled Comparison" |
| 讨论 | 增加"本文不主张该方法在三类场景外的普适性"，把失效条件提前到结果节末尾 |
| 声称动词 | demonstrate → show / indicate；outperform → compare favorably on X |

**降级的收益**：P-B 稿件的录用上限是"中修—小修可接受"，而硬撑 P-A 的稿件在缺对照时几乎必然被拒。**降级不是认输，是把稿件放到它真正能过的赛道上。**

降级的完整改写处方（逐节）见 `references/judgment-paths.md`。

## 五、判定结果的输出格式

报告里必须写成这样（不允许只写路径代号）：

```
路径判定：P-B 评估认知型
- 不能走 P-A，因为：P-A1 不满足（无等容量对照；Tab.4 仅有参数量不对齐的单模块消融）
  且 P-A4 不满足（缺口的负向证据仅有 §1 的文献引用，无本文自证）
- 不必落入 P-C，因为：未见因果越界声称（全文无 attribute to / due to 类表述），
  数字轨抽验 12 条全部可溯源
- 升级到 P-A 的最小成本：补一个等参数占位对照组（约 2 张卡 1 天），
  若该组性能接近本方案 → 永久留在 P-B；若明显低于本方案 → 可升级 P-A
```

**三句话缺一不可**：为什么不是 P-A、为什么不是 P-C、升级的最小成本。第三条是把判定变成可行动作的关键。

## 六、时间受限时的裁剪规则

用户说"下周必须投"时，**判定不变**，但"下一步顺序"按此裁剪：

| 剩余时间 | 只做这些 |
|---|---|
| ≥ 2 周 | 补最小升级实验 + 完成叙事降级 + 图表重分组 |
| 3–7 天 | 完成叙事降级 + 撤掉所有越界声称 + 补统计检验的报告（若已有数据，仅需重算） |
| ≤ 2 天 | 只做"撤掉越界声称"这一件事；并在报告中明确写"在未完成降级前投稿，预判大修—拒稿" |

**无论多急，撤掉越界声称永远做得完。** 这是所有裁剪里唯一不可省的项——因为它是专业诚信问题，也是 desk reject 的常见触发点。

## 七、判定自检（提交报告前问自己五个问题）

1. 我给的路径，如果换一个审稿人来会不会一致？（若不一致，说明判据写得不够硬，回 rubric 补条件）
2. 我说的"缺对照"，是指文中确实没有，还是我没找到？（找不到就写"未找到"，不写"没有"）
3. 我给的分数，每个维度能指回清单条目吗？
4. "升级到 P-A 的最小成本"我写清了吗？成本是否现实（不是"补做 10 个数据集"）？
5. 我的"预告结果"与路径自洽吗？（P-C 配"小修"是硬错误）
