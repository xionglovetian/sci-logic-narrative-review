## 四、漏洞卡片

### [V-01] 提升与参数量同步增加，无等参数对照，无法区分设计收益与容量红利
- **类别**：L3 因果
- **严重度**：P0
- **定位**：`§4.3` «we attribute the 2.6 mAP gain to the gating module» 配合 `Tab.3`
- **证据**：Tab.3 仅两行（完整模型、−模块A），无等参数占位行；§3.2 明示模块新增 0.8M 参数
- **审稿人原话**：「作者把 2.6 mAP 的增益归因于门控模块的设计，但该模块同时带来了 0.8M 的参数增量。缺少一个参数量对齐的占位对照，读者无法判断增益来自设计还是容量。请补充该对照，或下调相应结论。」
- **为什么有问题**：因果声明的唯一性要求排除替代解释。"参数变多"是本任务最高频的替代解释，未排除时，设计贡献不可采信。
- **修改处方**：在 Tab.3 增加一行"等参数占位模块（同 0.8M 参数、无门控逻辑）"，同预算训练；若无法补做，则全文删除 `attribute ... to` 类表述，并把贡献②改写为"在等训练预算下可复现的增益"。
- **复审判据**：Tab.3 出现参数对齐的占位行且报告其结果；或全文再无因果归因句。

### [V-02] 摘要的显著性声称缺少统计检验
- **类别**：D 数字与声称
- **严重度**：P1
- **定位**：`摘要` «significantly outperforms the baseline»
- **证据**：§4.1 未说明随机种子数与重复次数；全部表格无 p 值、无置信区间
- **审稿人原话**：「摘要使用了 significantly，但正文未提供任何统计检验，也未说明随机种子数量。请补充多 seed 的均值±标准差与相应检验，或删除该措辞。」
- **为什么有问题**：`significantly` 是统计术语，不是修辞。无检验即属术语误用，且会被直接读作过度声称。
- **修改处方**：二选一——① 用已有多种子结果补算均值±std 并做配对检验；② 改为 `compares favorably on ...`。
- **复审判据**：摘要不再出现 significantly，或 §4.1/Tab.2 出现检验结果。

### [V-03] 贡献②③实质同质，均为"提出新结构"
- **类别**：L4 贡献
- **严重度**：P1
- **定位**：`§1.3 末段` «we propose a novel gating module» / «we design a multi-scale fusion block»
- **证据**：三处摆放中，§1.3 的②③均以"提出结构"为主语；贡献③无专属支撑实验（Tab.2/3 均不单独检验融合块）
- **审稿人原话**：「三条贡献中的第二、三条都在陈述新结构，读者无法区分它们各自解决了哪个问题；且第三条没有对应的验证实验。」
- **为什么有问题**：贡献的作用是让读者快速区分"科学发现 / 方法 / 评估认知"三类产出。同质化会让审稿人认为本文只有一条贡献，从而质疑体量与创新性。
- **修改处方**：贡献①保留科学发现；②合并为一个方法贡献（含两模块，说明互补）；③改为评估认知类（如"在 X 场景下 mAP 高估实际部署收益"），并以 §4.4 的业务向分析作为支撑；若确无第三类证据，就写两条贡献，不硬凑三条。
- **复审判据**：三处贡献中至少含两类（发现/方法/评估认知），且每条标注专属表号。

### [V-04] 摘要与主表数字口径不一致且未注明
- **类别**：D 数字与声称
- **严重度**：P2
- **定位**：`摘要` «reaches 92.3%» 对 `Tab.2 行3` 的 92.31%
- **证据**：Tab.2 表注写明该列为 val 划分单次运行；摘要把该值当作整体性能陈述，未注明划分与重复次数
- **审稿人原话**：「摘要的 92.3% 与表 2 的 92.31% 来自验证集单次运行，但摘要未注明，容易被读作测试集结果。」
- **为什么有问题**：口径缺失会让读者高估结论强度；不同划分的数值不可混用作主结论。
- **修改处方**：摘要补注（`on the val split, single run`），或改用测试集多种子均值。
- **复审判据**：摘要数字带划分与重复次数说明。

### [V-05] Discussion 未写明失效条件
- **类别**：L6 边界
- **严重度**：P2
- **定位**：`§5 全节`（无任何 "degrades when / fails to" 类表述）
- **证据**：§4.4 已观察到小目标子集增益收窄，但 §5 未讨论该现象
- **审稿人原话**：「§4.4 显示增益在小目标子集上明显收窄，讨论部分却未提及。请说明该方法在何种条件下效果变差。」
- **为什么有问题**：主动写失效条件会显著降低审稿人挑刺意愿；不写则由审稿人代写，且写在拒稿理由里。
- **修改处方**：§5 增加一段"适用边界"：明确小目标占比高、分辨率低于 X 时增益收窄，并给出可能原因。
- **复审判据**：§5 出现至少一句具名失效条件，且与 §4.4 数据对应。

## 八、路径判定理由

- **为什么不是 P-A**：P-A1 不满足（无等参数占位对照，Tab.3 仅两行）；P-A2 不满足（无统计检验）；P-A5 不满足（贡献②③同质）。三项硬伤，不能按方法创新型投递。
- **为什么不是 P-C**：未命中 C2（数字轨抽验 9 条，7 条一致，2 条为口径缺失而非矛盾）；C3 虽命中（V-01 的因果归因），但该归因可通过系统性删除因果表述解除，无需补实验；C6 未命中（图像未见异常重复）。
- **升级到 P-A 的最小成本**：补一个 0.8M 参数的等参数占位对照组（约 1 天 GPU），并补 3 seed 的均值±std；若该组性能明显弱于本方案（差距 ≥ 2×std），可升级为 P-A；若接近，则永久定位 P-B。
